# ADR 0004 — Assess the process, not only the outcome

- Status: accepted
- Context: professionals are judged on how they work: gathering evidence
  before acting, least privilege, cost awareness, communication and not making
  things worse. A final-state rubric alone rewards blind fixes.
- Decision: the grader keeps the 100-point rubric and adds a process report
  computed from the session (read-only vs mutating commands, blind fixes,
  destructive actions, risky grants, constraint violations, ticket updates,
  questions asked, hints used). The report feeds the nine-dimension student
  model but does not change the rubric score, so pass/fail stays explainable.
- Consequences: incidents can be passed only by working professionally over
  time, the autonomy ladder has evidence, and feedback can say *how* to work
  better, not only what was missing.
